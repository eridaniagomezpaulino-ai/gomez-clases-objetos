## Descripción del programa
Programa de consola en C# que registra productos de la tienda TecnoPunto y muestra su información. Usa la clase `Producto`, que valida sus propios datos mediante propiedades y calcula el valor total que tiene en existencia.

## Datos de entrada
- Código del producto
- Nombre
- Precio
- Cantidad

## Datos que procesa
- Valida que el nombre no esté vacío.
- Valida que el precio sea mayor que 0.
- Valida que la cantidad no sea negativa.
- Calcula el valor total (Precio × Cantidad).

## Datos de salida
- Código, nombre, precio, cantidad y valor total de cada producto.
- Mensajes de error claros cuando un dato es inválido (el programa no se cierra y vuelve a pedir los datos).
